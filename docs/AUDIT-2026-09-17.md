# App + UI audit vs market leaders — 2026-09-17

Scope: everything except the Signal/research tab (dropped for now).
Compared against: TradeZella, TraderSync, Tradervue, Edgewonk, TradesViz (+ FX Replay for Studio).
Method: live walk-through of every page on the running app (desktop 1440px + mobile 375px), code grep, competitor feature pages/reviews.

## 2. UI / UX findings (from the live walk-through)

**Critical**
1. **Not mobile-usable.** At 375px the sidebar stays 208px, `main` is 167px wide, page scrolls horizontally (doc width 573px). TraderSync/TradeZella ship native apps; everyone else is responsive. Journaling right after a trade on your phone is the #1 capture habit.
2. **Global filter bar on every page** (Layout.tsx:14) — 9 controls, 2 rows, ~130px tall, shown on Trade detail, Import, Accounts, Calendar, Replay where it does nothing (Portfolio even has to say "account filter is ignored here"). Competitors put filters only on report/list pages.
3. **Dashboard is a long single stack of ~11 full-width panels.** No above-the-fold summary layout, not customisable. TradeZella: KPI row → Zella score + daily cumulative P&L side-by-side → calendar + recent trades side-by-side, drag/drop widgets.
4. **Trade detail puts the chart below the review block**, and the page is one ~15-card scroll (1.5k-line component). Competitors lead with chart + executions, notes beside it, stats in a side rail.

**High**
5. **Empty-by-default views.** Dashboard calendar + session heatmap open on the current month (Sept) → "no data" while the last trade was July; Journal opens on today → 0 trades. Default to the latest month/day with trades, or show "jump to last trading day".
6. **Nav clutter / overlap.** Signal still in nav (hide it). Replay vs Backtest vs Studio are three overlapping "simulate" pages → merge Backtest into Studio. Daily Plan card duplicated on Playbook and Journal. Sidebar still reads "PHASE 3".
7. **Typography.** All-monospace, 9–11px uppercase letter-spaced labels everywhere. Terminal aesthetic is fine for numbers; body copy/labels need a sans font and ≥12px for readability. No light theme (Edgewonk/Zella both have toggle).
8. **Warning noise.** Every trade row shows ⚠ (all have a gap) — an always-on warning stops meaning anything. Use a single "N trades need attention" banner + chip.
9. **Loading waterfall.** Analytics/Risk render 6–8 independent spinners ("Loading…") that resolve one by one. Use skeletons, or one combined endpoint per page.
10. **Econ Calendar feed stale** — shows "Manual · updated never"; yesterday's Fed/retail-sales rows have no actuals. Auto-refresh isn't running.

**Medium**
11. No keyboard nav on Trades (j/k, enter, next/prev trade on detail). Trade detail has no "next trade →" — reviewing a day means back-and-forth.
12. Tables: no sticky header, no column resize, no saved views.
13. Notes are plain textareas; no templates, no headings/bullets, no image paste inline.

## 3. Functional gaps vs market (ranked by value ÷ effort for this app)

### P0 — cheap, unlocks existing features
1. **Auto MAE/MFE from stored OANDA M1 bars.** We already fetch M1 around every imported trade, but `mae`/`mfe` are always inserted as `null` (import.js:295,606; index.js:2182). TradesViz computes these automatically. Filling them lights up the Excursion panel, efficiency, "gave back 1R", and the SL/TP Optimizer — which are all currently empty. Backfill existing trades on startup.
2. **Exit analysis: "price after exit"** — from the same bars: where price went 5/15/60 min after exit, best-exit-in-hindsight, left-on-table $ / R. TradesViz "Exit Insights", TraderSync exit analysis.
3. **Auto-generated insights** (deterministic, no LLM): ~10–16 statistical checks surfaced as cards on Dashboard ("You lose 2.1R on NY trades after a London loss", "Win rate drops after 3rd trade of day", "Holding >15m loses money"). TradesViz AI Coach = 16 checks; Edgewonk Edge Finder. We already have every input.

### P1 — review workflow (Edgewonk/Zella's real moat)
4. **Guided daily/weekly/monthly review.** A stepper: go through each trade of the day (chart, grade, followed plan, mistake tag, note) → recap → next. Add a monthly report (only week report exists). Edgewonk wins reviews on this.
5. **Psychology / tiltmeter per trade.** Pre-trade + post-trade emotion/confidence 1–5 scales (structured, not free tags) → P&L by emotional state. Edgewonk Psychology Lab / Tiltmeter.
6. **Notebook with templates.** Rich notes (markdown), folders (plan / recap / lessons / playbook ideas), saved templates for pre-market plan and session recap. TradeZella Notebook.
7. **Journaling reminders.** End-of-London / end-of-NY nudge: "3 trades unreviewed today" (browser notification; alert infra already exists in useSetupAlerts).

### P2 — capture automation
8. **Broker auto-sync.** Every leader's headline feature. Options for MT5/Equity Edge: (a) existing EA webhook — needs to be allowed on the account; (b) MetaApi-style investor-password cloud sync; (c) watch-folder auto-import of exported statements. Pick whatever the prop firm permits.
9. **Mobile/PWA quick capture.** Responsive layout + installable PWA with a "log/grade last trade" screen. Pairs with #7.
10. **Screenshot capture from chart.** One-click snapshot of the trade-detail chart saved as the trade's screenshot (we already render it); TradingView link paste → auto thumbnail.

### P3 — analytics polish
11. **Compare mode.** Two filter sets side by side (London vs NY, followed vs broke plan, this month vs last). Tradervue/TraderSync comparison reports.
12. **Report builder / pivot.** Pick metric × group-by (session, setup, tag, hour, weekday, custom field) → table/chart. TradesViz pivot grid. Replaces adding more bespoke panels.
13. **Customisable dashboard widgets** (show/hide/reorder, persisted).
14. **Year view calendar** + daily cumulative intraday P&L chart (Zella's signature widget).
15. **Monte Carlo / risk-of-ruin** from R distribution (Edgewonk-ish) — useful for prop DD limits specifically.

### P4 — multi-user (you + friend share the app)
16. **Profiles.** Right now separation is only by account. A lightweight profile switch (which accounts/instruments/playbook belong to whom) keeps each trader's dashboard clean.
17. **Share / mentor view.** Read-only link or Share card for a trade/day (Zella Spaces, Edgewonk journal sharing). Social share card exists; extend to a read-only day/week page.
18. **Backups / export all.** One-click DB export + scheduled local backup (no competitor loses your data; a local SQLite app can).
